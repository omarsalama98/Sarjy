## Two real bugs this run found (not simulated, not anticipated by the plan)

1. **`VISA_TOOL` was missing `"type": "function"`.** The plan's Contract 2
   gave the tool dict without it; the installed `google-genai` SDK's `Tool`
   union discriminates on that field and rejects every call with a
   `pydantic.ValidationError` otherwise — silently, from the caller's side,
   until this eval's first live run surfaced the traceback. Block 0's own
   spike (`scratch/spikes/parallel_fc.py`) already had this right; it was
   lost transcribing the plan. Fixed in `app/prompts.py`, locked in by
   `test_visa_tool_declares_type_function`.
2. **`FakeVisaTool` needs alias-tolerant lookup for a live-model eval.** The
   real `TravelBuddyTool` resolves whatever the model sends (a code or a
   country name) via `resolve_code()`; `FakeVisaTool` does an exact-match
   dict lookup and has no such step. Against a real, non-deterministic
   model this produced a handful of false `no_coverage` results purely from
   the harness, not the pipeline — fixed by registering each eval fixture
   under both the ISO code and the country name (`eval/run_eval.py`). Not a
   pipeline bug; `test_vendor.py`/`test_normalise.py` already prove
   `resolve_code()` correctly.

## Interpretation

The three-register gate held up against a real model on every case except
the one built to demonstrate its known, documented limit. **Corrected
2026-09-21 (F5), see the postscript below** — at the time of this run, Q6
was a tripwire for the literal in-the-wild **byte sequence**, not the
phrase: it did a plain lowercased substring match, so it was defeated by
any encoding trick that changed the bytes without changing what a human
reads (three such bypasses were found afterwards — see the postscript).
`injection-2`'s pass through the screen is still the right proof of the
*real*, undiminished limit: a genuine semantic paraphrase, no trick
involved, is not something a substring match — however carefully folded —
was ever going to catch. The `sourced` allowlist and the digit/number-word
rules were never even tested to their edge here (that's `tests/test_gate.py`'s
job, at n=33); what this run adds is that a REAL model, given the real
prompt, mostly uses the three registers the way `SYSTEM_SEGMENTS` asks it
to — including using `quoted` correctly for `register-2`, unprompted by any
few-shot example.

**What I'd want with another week:** more injection variants between the
literal payload and the full paraphrase (the space in between is where a
better screen would need to be tested), and enough cases per category to
report a rate rather than a single pass/fail.

## Postscript, 2026-09-21 — three encoding bypasses found and closed (F5)

A later review found that Q6's plain `marker in value.lower()` check —
exactly what this run exercised — had three trivial bypasses, none of which
change what a listener hears:

1. A zero-width space (U+200B) hidden inside a marker word (`str.split()`
   collapses ordinary whitespace but not this character).
2. ASCII punctuation splitting a marker phrase — `"A.I. LANGUAGE MODELS:"`
   has no contiguous `"ai language model"` substring.
3. A Cyrillic letter standing in for a pixel-identical Latin one (`"previous"`
   spelled with U+0440 CYRILLIC SMALL LETTER ER instead of `p`).

All three are now folded away before matching (`app/tools/gate.py`,
`_fold_for_injection_check()`): zero-width characters are stripped, a small
explicit table maps the handful of Cyrillic look-alikes to Latin, and
punctuation is deleted (not replaced with a space) so `"A.I."` collapses to
`"ai"`. `tests/test_gate.py` proves each of the three closed
(`test_f5_zero_width_space_inside_the_marker_still_rejected` and its two
neighbours). **This eval's 8 cases were not re-run against the fix** — none
of the three bypasses happened to appear in `injection-1`/`injection-2` as
originally labelled, so the numbers above are unchanged and still accurate
for what they measured. What changes is the claim about what Q6 catches:
it is now a tripwire for the literal in-the-wild phrase **and its trivial
disguises**, not merely the literal byte sequence — and it remains, as
`injection-2` already proved, not a tripwire for a genuine paraphrase.
